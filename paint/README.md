# Paint

Status: **architect interview and planning open; implementation gated**.

Paint is Malkuth's future small, direct image editor: a classic Paint-like tool
with transparent reusable clipart/composites and ordinary transfer from File
Manager. It deliberately refuses the layers/revision-management trajectory of
professional image editors while retaining whatever internal compositional
model is required to make placement and clipart honest.

Paint has no persistent side panels. Detailed Color, Help and other secondary
tools are ordinary owned popup dialogs.

Start with [`planning/README.md`](planning/README.md). A sibling task may begin
the interview at any time using
[`planning/FUTURE_THREAD_HANDOFF.md`](planning/FUTURE_THREAD_HANDOFF.md).
