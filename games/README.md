# Games

Status: **planning-only; implementation closed**.

Games is Malkuth's deliberately small collection of solitary and low-conflict
games. It provides useful software in its own right while exercising GUI.Forms
through cards, grids, boards, dialogs, animation, drag input, keyboard input,
sound policy, reduced motion, deterministic timers, and custom drawing.

Accepted roster:

- Solitaire (Klondike first)
- FreeCell
- Checkers
- Sudoku
- Crossword
- Atom Probe or a renamed hidden-clues equivalent
- Four Pegs, a four-peg deduction game
- Switchbox, an animated sequence puzzle
- Rendezvous Riders, a bidirectional route puzzle

All design and delivery records are routed from [`planning/README.md`](planning/README.md).
