# Text Editor

Status: **architect interview and planning open; implementation gated**.

Text Editor is Malkuth's future restrained one-document-per-window plain-text
and configuration editor. It opens actual text files without coercing them to
RTF, supports app-scoped hidden-file picking, provides modest format color hints
when available, and offers understandable find/replace without becoming an IDE
or a tabbed browser for documents.

Text Editor has no persistent side panels. Find/Replace, Characters, Help and
other secondary tools are ordinary owned popup dialogs.

Start with [`planning/README.md`](planning/README.md). A sibling task may begin
the interview at any time using
[`planning/FUTURE_THREAD_HANDOFF.md`](planning/FUTURE_THREAD_HANDOFF.md).
