## Scope

This round studies software that creates a temporary visual world around work:
installers, setup shells, first-run experiences, Visual Studio start surfaces,
and comparable professional authoring suites from roughly 2000–2012.

It asks separately about:

1. **World** — palette, illustration, fresco, framing, and density.
2. **Motion** — what moves, how much moves, and whether motion explains state.
3. **Instrumentation** — progress, component names, phase labels, and time.
4. **Ceremony** — arrival, completion, failure, and other rare transitions.
5. **Work surface** — how a serious tool presents projects, news, help, and
   commands without becoming a consumer landing page.

Music-player aesthetics are explicitly outside this round and are not used as
evidence. No cue should be inferred from a source that is not visible or
playable on the board.

## Verdict grammar

- **A — Accept:** the quality belongs in File Manager's design language.
- **D — Distill/adapt:** preserve the principle, but redraw or constrain it.
- **R — Reject:** treat it as an anti-model.
- **U — Unseen/unclear:** obtain a better recording or still before deciding.

The 17-object board saves its 68 atomic verdicts locally and exports a compact
comma-separated answer.

## Deliberate comparisons

- Visual Studio installer identity versus ordinary Windows Installer utility UI.
- Visual Studio .NET/2003, 2005/2008, 2010, and 2012 start surfaces.
- Compact wizard side-art versus full-window branded setup worlds.
- Whistler, XP, Longhorn, Vista, and Windows 7 first-run ceremony.
- Ambient animation versus motion that communicates a phase or spatial change.
- Honest technical instrumentation versus decorative waiting theater.

## Interpretation guardrails

- Accepting an installer's fresco does not accept its wizard layout.
- Accepting a transition does not authorize constant motion in ordinary file
  navigation.
- Accepting a full-screen OOBE world does not authorize a File Manager home
  page; it may apply only to installation or another rare ceremony.
- Accepted product branding must be translated into File Manager's own house
  style. It is never permission to imitate another product's marks.
- A recording's narration, music, video-editing style, and host OS chrome are
  not part of the verdict unless a cue names them explicitly.
