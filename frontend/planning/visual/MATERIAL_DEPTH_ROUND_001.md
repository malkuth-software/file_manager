# Material depth and pattern round 001

Status: **awaiting architect verdicts**.

Interactive board: [`material-depth-atlas.html`](material-depth-atlas.html)

## Purpose

This round is not a vote between “skeuomorphic” and “flat.” Those words hide
several independent design systems. The board separates:

- edge relief;
- plane stacking;
- inset instruments and displays;
- sculpted object icons;
- illustrated identity fields;
- diegetic controls;
- procedural ornamental patterns;
- and the geographic depth assigned to daily, transient, and ceremonial UI.

The candidate language lives between the literal machinery of JumpStart and
the professionally distilled instruments of Windows Control Panel, SkyOS, and
the Microsoft Update Catalog. Generic modern design is not a candidate. SolusOS
is included only as a declared boundary case.

## Board families

1. **Microsoft Update Catalog after a real search** — illustrated identity
   abruptly resolving into a dense, ruled utility surface.
2. **Windows 95/98/Me configuration** — object grids, physical widgets, etched
   groups, miniature UI dioramas, and illustrated category views.
3. **SkyOS** — shallow custom depth, soft corners, small sculpted icons, window
   shadows, and severe professional instrumentation.
4. **SolusOS Eveline** — a flat-ish/dark 2012 boundary case without Metro's
   typographic or monochrome-icon dogma.
5. **AOL 4.0** — jewel-like destination objects over conventional utility
   machinery.
6. **JumpStart Mystery Mountain** — an intentionally childish extreme from
   which individual physical-control ideas may or may not survive.
7. **Frozen Windows screensavers** — static pattern families only: Pipes, Maze,
   Flower Box, and Flying Windows. Motion is not being judged.

## Depth loci to establish

For every accepted material cue, later rounds must decide where it is legal:

- **D0 content:** text, file rows, whitespace, and data should normally be calm.
- **D1 controls:** shallow relief may communicate click, input, selection, or
  drag affordance.
- **D2 instruments:** previews, meters, timelines, and state displays may become
  deeper and more explicitly physical.
- **D3 framing:** title frescoes, inspector wells, and bounded tools may use
  stronger plane separation.
- **D4 ceremony:** installation, completion, exceptional empty states, and rare
  long operations may create an illustrated world.

The board asks about forms first. Placement is stated only where the visual
cannot be judged meaningfully without a candidate use.

## Exclusions

- No music-player source families.
- No animation verdicts in this round.
- No generic modern cards, pills, floating action buttons, borderless text
  controls, or monochrome-glyph systems.
- No assumption that accepted low-resolution source pixels should be copied.
  Geometry, material, color relationship, and object semantics are the evidence.
