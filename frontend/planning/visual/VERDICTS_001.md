## First synthesis

This is not a vote for generic retro styling. It selects a narrower grammar:

- **Accepted structure:** one-folder-per-window semantics; explicit classic
  menu/toolbar/address organization; stable labelled commands; multiple honest
  view modes; direct file attributes; compact item-count/status reporting; QNX-
  like control precision; OS/2 object semantics; square unequivocal edges.
- **Accepted richness:** Watercolor titlebar fresco; white work canvas; distinct
  active/inactive states; Ergonomic alternate; high-color material icons;
  occasional orange; tiny meaningful status glyphs; dense metadata; brushed
  metal; handcrafted eccentric icons; deliberately large/soft Aqua geometry in
  selected contexts.
- **Adapt rather than copy:** Watercolor ambient field and keyline; classic
  geometry; green affirmative accent; monochrome icon-carrying base; dense
  professional controls; pinstripe; column navigation; unified title/toolbar;
  candy controls; compact sidebar typography; GNOME roominess; OS/2 notebook
  properties.
- **Rejected ornamental structures:** phpBB bars/borders/alternating rows/table
  feeling; OPENSTEP monochrome base, Shelf, icon path, and prominent scrollbars;
  BeOS title tab; IRIX palette, Motif bevels, and icons; Longhorn semantic banner
  and dark side structure; Finder source-list/sidebar abstraction; luminous
  collapsible category headers.
- **Important distinction:** physical, click-capable controls are accepted
  (`V052`, `V057`, `V216`) while deep Motif beveling (`V077`) is rejected.
  Material affordance should be crisp and shallow, not heavy.
- **Open reference:** `V207` needs a better image before the bounded optional
  task-region idea can be judged.

## Consequent visual hypothesis

The emerging surface is a white, object-centered working field held by precise,
square, materially clickable chrome. Color and illustration concentrate in the
title fresco, object icons, compact status signals, and exceptional ceremonial
states. Structural hierarchy should come from geometry, spacing, labels, and
stable placement—not shaded category bars, alternating rows, nested borders, or
large semantic panels.
