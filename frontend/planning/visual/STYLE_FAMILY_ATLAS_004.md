## Question under test

The approved twelve-color atmosphere axis changes color relations. It does not
answer how the interface itself is built, edged, grouped, weighted, or lit.
This atlas therefore holds **Sapphire Dusk** constant and varies the structural
reading of the same one-window, one-location File Manager. Candidate 02 is now
the owner-directed **House Composite**; the other eleven remain useful controls
and atom sources.

**GIVEN:** the comparison must contain strongly changed directions, not twelve
minor theme variations. The target remains a professional, industrial,
classically deep, high-definition information instrument with the period-
ambiguous richness of “Microsoft Encarta '00 ultra HD deluxe premier edition.”

**GIVEN:** all candidates retain the accepted product topology: classic menu,
labelled task shelf, path/search row, collapsible folder tree, one white object
field, collapsible selection/properties pane, and local status line. No candidate
introduces tabs, a dual pane, cards as the file field, provider-branded roots, or
an immediate-mode GUI.

## Shared source-language boundary

These are transformations of accepted or distilled atoms, not copies of source
products. Watercolor supplies the fresco; Encarta supplies jewel identity and
reference-software ceremony; Office/Studio supplies professional grouping; Aqua
supplies material finish; QNX supplies precision; OS/2 supplies object weight;
Delphi/C++Builder supplies tool density; MSN supplies labelled jewel objects;
SkyOS supplies bounded pearl planes.

Literal BeOS title tabs, Motif-wide deep bevels, literal IRIX color, Longhorn
dark structural dominance, and Finder source-list topology remain rejected.
“Machined Workstation” is therefore an industrial relief study, not a proposal
to reinstate a literal NeXTSTEP skin.

## Office ribbon reference extraction

The owner requested explicit consultation of Word's 2017-era, 2019, and 2021
ribbon styling. The usable result is a structural extraction, not a copy:

- **OBSERVED:** Microsoft's ribbon documentation for Word 2016, 2019, and 2021
  describes and illustrates a stable anatomy of tabs, groups, and commands; a
  selected tab exposes the full command surface and groups remain the unit of
  customization. [Microsoft Support: Customize the ribbon in Word](https://support.microsoft.com/en-us/word/customize-the-ribbon-in-word)
- **OBSERVED:** Microsoft's Word 2021 visual-refresh description names a clean,
  clear ribbon, neutral palette, monoline iconography, and softer window
  corners. [Microsoft Support: What's new in Word 2021](https://support.microsoft.com/en-US/Word/what-s-new-in-word-2021-for-windows)
- **OBSERVED:** the simplified ribbon compresses commands to one line and moves
  missing actions into dropdowns or overflow. The File Manager keeps its full
  labelled shelf because the accepted surface values visible task commands; it
  borrows the quiet grouping and restrained overflow behavior, not the one-line
  reduction. [Microsoft Support: Using the simplified ribbon](https://support.microsoft.com/en-us/word/using-the-simplified-ribbon-in-word-for-the-web)
- **INFERENCE:** the useful 2017/2019-era cues are the saturated application
  identity band, separate tab rail, white ribbon field, large/small command
  hierarchy, thin group dividers, and labels at the group boundary. The useful
  2021 cue is softer, quieter containment. The modern flat/monoline icon
  treatment is rejected because the approved icon direction requires material
  depth.

## Owner-directed House Composite

**GIVEN:** zone the primary specimen instead of applying one source family to
the whole window:

1. **Ribbon and above:** Watercolor identity fresco plus Office Pearl material,
   with a Word-like tab rail, white pearl command field, thin group dividers,
   and group labels.
2. **Below the ribbon:** Workshop Graphite chassis for navigation, gutters,
   splitters, collapse actuators, and status, while the object field stays white.
   **GIVEN correction:** use subtle middle-value graphite texture, not black;
   visible pane seams are 3 px or thinner even when their hit targets are wider.
3. **Inside folder/search/preview panes:** Studio 2003 cues—warm-neutral caption
   stock, fine blue-grey edges, compact section bars, and factual density.

The mockup's exact radii, gradients, texture frequency, and values remain
**CANDIDATE**.

## What actually varies

The HTML does not merely swap a color token. Each style changes at least four of
the following while retaining semantic roles:

- title construction and identity treatment;
- command orientation, grouping, plate visibility, and density;
- menu and navigation material;
- corner and edge grammar;
- cast-shadow and inset-depth strength;
- pane-caption treatment;
- splitter/collapse-actuator material;
- selection focus force;
- structural light/dark balance.

The file objects and their icon semantics are intentionally held constant. This
lets the owner judge whether the chrome is supporting or competing with the
approved deep icon direction.

## Review discipline

The twelve families are **CANDIDATE** and deliberately broad. Selecting one
does not select CSS values, GUI.Forms widgets, serialized surface schema, or a
renderer strategy. A useful response may select a family, combine named atoms
from two or three families, or reject a family with a precise failure mode.

The primary specimen is House Composite. Workshop Graphite, Studio 2003,
Office Pearl, and Watercolor Instrument remain the most useful source controls:
each isolates one part of the synthesis and makes it possible to identify which
layer is helping or harming the whole.

## Open review questions

1. Does House Composite read as one authored instrument, or can the transition
   from pearl ribbon to graphite chassis still be felt as a seam?
2. Should the dark Workshop chassis remain in comparison, or does it violate
   the intended bright optimism even when the file field stays white?
3. Is Aqua Technical's depth appropriately classic-iOS, or too soft for the
   serious industrial target?
4. Should command density follow QNX/Delphi horizontally, or preserve the
   larger object-like shelf of Encarta/MSN?
5. Which single family has the best pane-caption and splitter treatment?
