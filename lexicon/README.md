# Lexicon

Status: **planning-only; implementation closed**.

Lexicon is Malkuth's bounded local dictionary and word-corpus provider. Its
smallest proof is exact term in, typed definitions out. It also supplies a
versioned vocabulary enumeration to Games/Crossword, beginning with a
Shakespeare-derived corpus.

It is not an application, AI assistant, general semantic graph, web dictionary,
or part of Engine's exact file catalogue. Start at
[`planning/README.md`](planning/README.md).
