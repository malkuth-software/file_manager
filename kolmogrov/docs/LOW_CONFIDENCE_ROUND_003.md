## Outcome

Five low-confidence mathematical items now have exact finite boundaries. The
sixth—novelty—was narrowed by a scoped primary-source audit.

The result is not a universal hash construction. It is a more precise support
selection program:

```text
task observations
  -> least joint support only where simultaneous sufficiency is required
  -> flow-closed refinement
  -> protected-separation graph and width lower bound
  -> independently addressable detail blocks

  -> quantization with explicit certification
```

## 1. Universal cross-modality support

**REJECTED** as support-neutral.

The minimum shared exact support is the partition induced by the joint task
observation. The least strict obstruction has only three fine states: two
crossing binary observations each need two states alone but three jointly.

Surviving candidate: modalities may share the support algebra, contraction law,
evidence schema, and verification contract while using distinct observation
partitions or adapters. Combining them is charged by the size of their joint
refinement.

Proof: `formal/T-UNIVERSAL-SUPPORT-1.md`.

## 2. One fixed width

**REJECTED** as a content-length law; replaced by a task-relative certificate.

Construct a graph whose edges are protected pairs the code may not merge. The
minimum binary separation width is

```text
ceil(log2 chi(G)).
```

The triangle is the least obstruction to one bit. Hamming-margin requirements
produce a stricter graph-labeling problem. Width therefore versions the
protected graph and margin, not merely an object-length ceiling.

Proof: `formal/T-OBSTRUCTION-CODE-1.md`.

## 3. Energy as information

**REJECTED** without a joint probabilistic observation model.

Two binary detail channels can have the same marginal distribution, every
marginal moment, and identical unit energy while carrying respectively one bit
and zero bits about the target. Conversely, invertible rescaling preserves one
bit while making energy arbitrary.

Surviving rule: geometric energy, atomic SNR, conditional information, and task
loss remain separate ledgers. A bridge must declare conditional laws, prior,
noise, and readout.

Proof: `formal/T-ENERGY-INFORMATION-1.md`.

## 4. Static universal schedule

**REJECTED** unless task requirements are nested.

A single progressive block order realizes every task's least sufficient support
without overhead exactly when those block sets are totally ordered by
inclusion. Two tasks requiring separate singleton blocks are the least
obstruction.

Surviving candidate: independently addressable channels with an optional
task-conditioned serialization. A common prefix is justified only for a nested
task family or with explicit per-task excess support.

Proof: `formal/T-NESTED-SCHEDULE-1.md`.

## 5. Automatic interaction sparsity

**REJECTED** universally.

For `p x q` product axes, the marginal-invisible interaction space has
dimension `(p-1)(q-1)`. Every universally faithful linear certificate needs all
of that dimension. `2 x 3` is the least product where one scalar necessarily
misses an interaction.

Surviving candidate: sparse interaction support is valid only relative to a
low-dimensional relevant span, finite protected obstruction family, or accepted
ambiguity. Held-out relevant differences directly falsify it.

Proof: `formal/T-INTERACTION-SPARSITY-1.md`.
