# T-SYMBOL-JACOBIAN-1: exact source-symbol flow through projected certificates

Status: **HYPOTHESIS with complete finite paper proof; mixed edits and File
Manager thresholds remain open**.

## Definitions

Fix a one-atom-per-source-position observation stream `x`, deletion radius `t`,
degree `m`, and certificate subset

```text
I_c = (i_0 < ... < i_(m-1)).
```

For each weakly increasing offset state

```text
d in Omega = {0 <= d_0 <= ... <= d_(m-1) <= t},
```

the exact observed pattern is

```text
P_c(x,d) = (x_(i_0+d_0), ..., x_(i_(m-1)+d_(m-1))).
```

The idempotent certificate set is `S_c(x)={P_c(x,d):d in Omega}`.

Let `x'` differ from `x` only at source position `j`. Define the affected
offset states

```text
U_(c,j) = {d in Omega : some r has i_r+d_r=j}.
```

Define exact removed and added pattern sets

```text
R_c = S_c(x) \ S_c(x'),
A_c = S_c(x') \ S_c(x).
```

For projection view `s`, let `N_(c,s)` and `M_(c,s)=1[N>0]` be its count and
occupancy vectors from T-PROJECTION-REFINEMENT-1.

## Localization theorem

Every offset state outside `U_(c,j)` produces the same pattern before and after
the mutation. Therefore all exact certificate change is generated by
`U_(c,j)`, and

```text
|R_c| <= |U_(c,j)|,
|A_c| <= |U_(c,j)|,
|R_c|+|A_c| <= 2|U_(c,j)|.
```

This is the exact combinatorial source-symbol Jacobian support. A certificate
with `U_(c,j)=empty` has zero response. The converse is false: an affected state
can be redundant in the idempotent set.

## Exact projected Jacobian

The binary Jacobian contribution of certificate `c`, view `s`, and mutation
`j` is

```text
J_(c,s,j) = M_(c,s)(x') - M_(c,s)(x).
```

Its squared binary `l2` energy equals its Hamming support:

```text
E_(c,s,j)
 = |support M_(c,s)(x) symmetric_difference
      support M_(c,s)(x')|.
```

Equivalently, it counts cells whose occupancy crosses zero. Hence

```text
E_(c,s,j) <= |R_c|+|A_c| <= 2|U_(c,j)|.
```

Equality need not hold. Multiple removed patterns can share one clearing cell;
an added pattern can enter an already occupied cell; removed and added patterns
can exchange inside one cell.

The response is exactly zero iff every projected cell occupied before remains
occupied after and conversely. This gives three distinct zero-response causes:

1. **observation invariance:** the view maps the source replacement to the same
   atom;
2. **history-set redundancy:** affected offset states change but `R_c=A_c=empty`;
3. **projection cancellation:** exact pattern events exist but no cell crosses
   zero.

These causes must be reported separately.

## Schedule response and SNR

For a schedule `C` and view family `V`, define mutation energy

```text
E_j = sum_(c in C, s in V) E_(c,s,j).
```

This is computable exactly from occupancy masks. Under separately declared
binary noise energy `N_j>0` and threshold `Gamma`, mutation `j` is supported
only when

```text
E_j / N_j >= Gamma.
```

Certificate incidence `|{c:U_(c,j) nonempty}|` is only an upper-support
opportunity. It cannot replace `E_j` because redundancy and collision can erase
every incident contribution.

## Least collision obstruction

One changed exact pattern `p -> q` is enough for projection invisibility when
`p` and `q` occupy the same cell. No smaller pattern event exists. This is the
absolute least projection-cancellation witness.

## Least exact history-redundancy witness

Take radius two, degree three, source

```text
x  = aaaaab,
x' = aaaabb,
j  = 4,
I  = (0,1,3).
```

For `x`, the third gathered source position is `3+d_2`. It is `b` only when
`d_2=2`; the first two gathered positions are always `a`. Thus

```text
S_I(x) = {aaa,aab}.
```

For `x'`, positions four and five are both `b`; the first two gathered positions
remain `a`, and the third is `a` or `b`. Therefore

```text
S_I(x') = {aaa,aab}.
```

The mutation participates in offset states but the exact idempotent certificate
does not change.

This witness is minimal in source length among binary exact-deletion
certificates. Radius one has only the three pair states `(0,0),(0,1),(1,1)`;
checking the four possible positional roles of the mutated source atom shows an
old or new ordered pair cannot all be supplied by the unaffected states. Radius
two first permits source length five. At length five, the sole degree-three
certificate is the set of all length-three subsequences. A binary bit flip
changes the total one-count from `w` to `w+1` or conversely: if `w<=2`, the new
set contains a triple with `w+1` ones impossible before; if `w>=3`, use the
same argument on zeros. Hence length five cannot be redundant, and the
length-six witness is least. Larger radii require source length at least seven.

## Observation invariance is not breakdown

Under Filename Profile 001, replacing `A` by `a` changes the literal atom but
not the anchored-fold or structural-letter atoms. Their zero Jacobian is a
declared invariance. Replacing one digit by another leaves the structural view
unchanged but must remain visible in literal/fold views. A production support
gate therefore names required view responses per mutation class rather than
demanding that every view respond to everything.

## Boundary

This theorem covers one same-length source-position substitution in a
source-anchored stream. Insertions, deletions of the source stream,
transpositions, whole-string normalization, token boundary changes, projection
row selection, and posting work remain separate objects. The reference audit in
`src/kolmogrov/projection.py` computes every term above without treating its
execution as proof.
