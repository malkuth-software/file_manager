# E10: filename observation and source-symbol Jacobian

Status: **finite research-profile audit; not a filename relevance benchmark**.

E10 applies Filename Observation Profile 001 to named substitution
obstructions. It separates:

- intended observation invariance;
- exact history-set redundancy;
- projected occupancy cancellation;
- projected posting entries.

The atlas is generated in the source and contains no private filesystem names.
It compares a failed 16-cell low-bit affine projection with a 16-cell balanced-
bit diagnostic. Neither is a selected configuration.

Run from the Kolmogrov root:

```sh
python3 experiments/e10_filename_jacobian/run.py
```
