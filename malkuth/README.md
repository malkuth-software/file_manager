# Malkuth

Status: **suite/release planning; website and installer implementation remain
closed**.

**Malkuth** is the public suite and distribution identity for the unified local
desktop system. It does not replace the names or independent versions of File
Manager, Paint, Text Editor, Games, Lexicon, Orchestrator, Engine, GUI.Forms, or
Kolmogrov.

> **Curious, Concise, Friendly.**
